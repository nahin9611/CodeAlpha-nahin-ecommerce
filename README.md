# Nahin Ecommerce 🏍️

A professional, full-stack MERN (MongoDB, Express, React, Node.js) e-commerce platform dedicated to high-quality motorcycle gear, touring accessories, and rider equipment. 

Built with a focus on robust security, dynamic state management, and administrative control, this platform serves as a complete digital storefront solution.

## 🌟 Key Features

*   **Secure Authentication:** JWT-based user authentication with encrypted passwords (bcryptjs) and HTTP bearer tokens.
*   **Role-Based Access Control (RBAC):** Custom React route guards protecting user profiles and restricting the Admin Command Center exclusively to authorized personnel.
*   **Admin Command Center:** A master dashboard featuring full CRUD (Create, Read, Update, Delete) capabilities for database inventory management.
*   **Global State Management:** Seamless shopping cart and user session handling utilizing React Context API and LocalStorage.
*   **Advanced Data Searching:** Backend-integrated keyword search utilizing MongoDB's `$regex` operator for partial, case-insensitive querying.
*   **Responsive UI/UX:** Clean, modern interface fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Technical Stack

**Frontend:**
*   React.js (Functional Components & Hooks)
*   React Router DOM (Dynamic Routing)
*   Context API (State Management)
*   Axios (HTTP Client)
*   CSS3 (Custom Responsive Styling)

**Backend:**
*   Node.js & Express.js (RESTful API)
*   MongoDB & Mongoose (NoSQL Database & ODM)
*   JSON Web Tokens (JWT) & Bcrypt.js (Security)
